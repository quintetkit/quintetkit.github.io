.claude/settings.json に書いても効かないキー 71 個

設定キーにはどのファイルから書けば効くかが決まっているものがあります。

厄介なのは、間違った場所に書いてもエラーにならないことです。 JSON としては正しく、起動時の警告も出ず、--debug にも出ません。ただ効きません。

公式の設定表のスコープ列を数えると、71 個がこれに当たります。

スコープ 効く場所 件数
Managed 組織が配る管理設定（managed-settings.json）からのみ 39
User or managed ~/.claude/settings.json か管理設定からのみ 23
User, local, or managed ユーザ設定・settings.local.json・管理設定からのみ（settings.local.json からは効きます） 3
Global config ~/.claude.json からのみ 6

Any file（152 個）はどこに書いても効くので、ここには載せていません。

確かめ方

手で照らし合わせる表ではないので、ツールに任せてください。

npx @quintetkit/ccheck

warn  .claude/settings.json:63
      `autoMode` applies from user or managed settings only. It has no effect from this file.

注意点が2つあります

~/.claude/settings.json はユーザ設定そのものです。 パスの見た目はプロジェクトの設定ファイルと同じですが、そこに User or managed のキーを書くのは正しい書き方です。

入れ子のキーは点つなぎの名前で決まります。 sandbox.network.strictAllowlist は sandbox の下に書きますが、スコープが決まっているのはその完全な名前のほうです。 sandbox そのものは制限されていません。
